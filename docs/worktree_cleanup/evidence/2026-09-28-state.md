## Lessons from the August campaign and September review

1. The August campaign's final target list was exact and owner authorized. Its
   earlier prefix and count assumptions failed when similarly named directories
   and new worktrees appeared. Use exact identities and a frozen manifest for each
   later operation; never promote an old count or wildcard to current authority.
2. The shared checkout changed branch during the August attempt. Do not run a
   blanket pull, add, reset, clean, or checkout in today's dirty main checkout.
   Reconcile source work in an isolated, reviewed lane while preserving its local
   changes and untracked files.
3. The August attempt correctly recorded a partial result when ambiguous artifact
   paths remained. Keep partial and blocked outcomes explicit; a later successful
   action must have its own receipt and cannot rewrite the earlier event.
4. Git object presence, branch reachability, remote advertisement, working-tree
   dirt, and physical backup are different proofs. Test each claim directly.
5. Database classification requires schema-wide measurement on disposable copies,
   comparison with the tracked catalog seed, and provenance review for ambiguous
   rows. Preserve first when provenance is unresolved.
6. Preserve evidence before reducing it. A content hash can identify identical
   bytes, but it cannot by itself prove that two paths or runs have the same role.
7. A backup receipt is incomplete without a later restore and retention check.
   The August summary named preservation artifacts that are now absent; a historical
   `RESOLVED` baseline entry does not repair that loss.
8. A status sentence can be falsified by the very commit that publishes it. The
   2026-09-08 "unpublished and unmerged" statement was carried to `main` inside the
   commit that published the bytes it described. Verify a publication claim against
   the pinned content hashes on the remote, not against the prose or the PR title.
9. A filesystem creation timestamp distinguishes a same-volume move from a copy and
   can refute an "old residue" attribution outright. Check it before assigning a
   directory to a past campaign.
